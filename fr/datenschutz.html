Déclaration de protection des données

État : 18 novembre 2026. Traduction ; en cas de doute, la version allemande fait foi.

En bref : l’app Familienfahrtenbuch ne collecte aucune donnée. Il n’y a pas de serveur propre, pas de publicité, pas d’analyse et pas de suivi. Ce que vous saisissez se trouve sur votre iPhone et dans iCloud et n’est visible que pour votre famille. Nous n’y avons pas accès.

1. Responsable

Christian Kettler, Suisse
E-mail : support@familienfahrtenbuch.ch

Cette déclaration se fonde sur la loi suisse sur la protection des données (LPD).

2. Données dans l’app

Dans l’app, vous saisissez par exemple : le nom de la famille, les noms des personnes, les voitures avec leur plaque, les trajets avec l’heure, le kilométrage, le but et une note, les pleins, les frais, les réservations et les paiements de compensation.

  • Lieu de stockage : les données se trouvent sur votre iPhone. Si vous êtes connecté à iCloud, l’app les enregistre en plus dans la base de données iCloud privée de votre identifiant Apple, afin qu’elles soient synchronisées sur les appareils de la famille. iCloud est exploité par Apple ; c’est la politique de confidentialité d’Apple qui s’applique. En tant que fournisseur de l’app, nous ne pouvons pas consulter ces données.
  • Partage avec la famille : si vous invitez quelqu’un, cette personne voit et modifie toutes les données de la famille. Vous décidez vous-même qui est invité. Les participants voient aussi qui d’autre fait partie de la famille.
  • Réglages sur l’appareil : qui vous êtes dans l’app, la langue choisie et si les notifications sont activées ne sont enregistrés que sur votre iPhone. Rien n’est transmis.
  • Notifications : les notifications de réservations sont créées par votre iPhone lui-même à partir de la synchronisation iCloud. Aucun serveur n’envoie de notifications.
  • Export : l’app ne crée l’export en fichier CSV que si vous le déclenchez. Vous décidez où vous envoyez le fichier.

3. Supprimer des données

  • Vous supprimez des entrées individuelles directement dans l’app.
  • Réglages → « Réinitialiser » supprime toutes les données de la famille, aussi chez les personnes invitées.
  • Vous quittez une famille sous Réglages → « Voir les participants ».
  • Si vous supprimez l’app, iOS efface les données sur l’iPhone. Vous gérez les données dans iCloud dans les réglages iOS sous votre nom → iCloud.

4. Demandes par e-mail

Si vous nous écrivez, nous recevons votre adresse e-mail et le contenu de votre message. Nous les utilisons uniquement pour répondre à votre demande et ne les transmettons pas. La boîte aux lettres se trouve chez Infomaniak Network SA à Genève, Suisse. Nous supprimons les messages dès qu’ils ne sont plus nécessaires.

5. App Store et TestFlight

L’app est proposée via l’App Store d’Apple. Pour le téléchargement et la mise à jour, c’est la politique de confidentialité d’Apple qui s’applique. Si vous avez autorisé sur votre iPhone le partage des données d’analyse avec les développeurs, Apple nous fournit des rapports de plantage et des statistiques d’utilisation sans indication de personne. Qui teste l’app via TestFlight nous communique par Apple son nom et son adresse e-mail ainsi que les commentaires envoyés volontairement.

6. Ce site

Ce site est hébergé chez GitHub Pages (GitHub, Inc., États-Unis). Lors de la consultation, GitHub traite des données techniques comme l’adresse IP pour livrer la page et la protéger contre les attaques. Des données peuvent alors être transmises aux États-Unis. Les détails figurent dans la déclaration de confidentialité de GitHub. Le site lui-même ne pose pas de cookies, ne contient pas d’analyse et ne charge ni polices ni scripts de tiers.

7. Vos droits

Vous pouvez demander des renseignements sur vos données, les faire rectifier ou supprimer. Écrivez-nous pour cela à support@familienfahrtenbuch.ch. Comme nous n’avons pas les données de l’app, cela concerne surtout les demandes par e-mail. Vous gérez vous-même les données dans l’app.

Vous pouvez aussi déposer une plainte auprès du Préposé fédéral à la protection des données et à la transparence (PFPDT).

8. Modifications

Si l’app change de sorte que cette déclaration n’est plus exacte, nous l’adaptons. C’est la version publiée ici qui fait foi.
